# Matriz de empty states — v1.84.0

| Superfície | Estado vazio honesto | Ação permitida |
|---|---|---|
| Agenda | nenhum agendamento real para filtros | criar agendamento |
| Triagem | nenhum registro real retornado | criar e salvar triagem |
| Consulta | nenhum atendimento real | iniciar somente a partir de vínculo real |
| Fechamentos | nenhum fechamento real | mutações desabilitadas com motivo |
| Financeiro/Pagamentos | nenhuma origem/valor real | sem geração ou pagamento fictício |
| Admin SaaS | agregado/configuração indisponível | ação desabilitada e dependência explicada |
