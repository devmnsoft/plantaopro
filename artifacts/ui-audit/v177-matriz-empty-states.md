# Matriz de empty states — v1.77.0

| Superfície | Mensagem honesta | Valor presumido |
|---|---|---|
| Dashboard/API indisponível | Resumo ainda não disponível | Nenhum; fallback zero não é renderizado |
| Agenda | Nenhum plantão retornado hoje | Nenhum |
| Cobertura | Nenhum risco entre registros retornados | Nenhum |
| Financeiro | Nenhuma movimentação no recorte | Nenhum pagamento/status |
| Faturamento | Lista, vazio ou erro são estados distintos | Sem zero/pago padrão |
| Assinatura | Assinatura ausente ou erro explícito | Sem plano/limite inventado |
| Notificações | Nenhuma atualização recente | Sem contador/item |
| Relatórios | Recurso sem endpoint indisponível com motivo | Sem histórico/arquivo |
