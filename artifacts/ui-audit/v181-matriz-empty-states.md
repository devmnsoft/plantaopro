# Matriz de empty states — v1.81.0

| Bloco | Estado honesto | Não presume |
|---|---|---|
| Tenant/Admin | agregado indisponível | organização, prontidão ou contagem |
| Assinatura | vínculo não retornado | plano, preço, status, uso ou limite |
| Usuários/perfis | fonte/policy necessária | usuário ou concessão |
| Permissões | matriz efetiva indisponível | autorização por perfil |
| Auditoria/LGPD | consultar eventos persistidos | evento, acesso ou evidência |
| Relatórios | endpoint necessário | arquivo, histórico ou última geração |
| Configurações | status não informado | configurado ou pendente |
