# Matriz de empty states — v1.80.0

| Tela | Mensagem honesta | Não presume |
|---|---|---|
| Faturamento | API não retornou contas | valor, status ou histórico |
| Financeiro | nenhum lançamento no filtro | saldo zero, pendência, glosa ou repasse |
| Pagamentos | nenhum pagamento na competência | pendente, pago, comprovante ou valor zero |
| Glosas/Repasses | exibidos apenas com fonte vinculada | existência, responsável ou valor |
| Relatórios | endpoint auditável ainda necessário | arquivo ou última geração |
